Deep Dive: LoRA Hands-On at Runnable Scale

Tonight you'll be able to: bolt LoRA adapters onto the actual tiny GPT you built on Day 42, fine-tune it to answer in your trading-journal voice while training 55,296 of its numbers, and re-prove Day 53's three promises at full model scale: exact init, a bit-for-bit frozen base, and a merge that costs nothing to serve.

The one idea

Day 53 was the concept on a hand-set 3 x 2 toy: freeze W, train the patch dW = B x A, merge it back. Tonight there is no new concept - there is a new scale. The base is the real model from Day 42, the second voice is a trading journal, and every Day 53 promise gets re-proven at 814,643 parameters.

One piece of stage-setting, stated plainly: Day 42's script never saved a checkpoint, so there is no weights file to load. Part 2 of the code re-pretrains the identical architecture on the identical Shakespeare corpus (800 of Day 42's 1,200 steps - the base only needs to be fluent, not finished). In a real job this is where you load the checkpoint and start at Part 3. The LoRA workflow is identical either way; only the base's provenance differs.

Before any patching, the code counts the model from its tensors - and finds 814,643 parameters, not the 618,035 on Day 42's formula card. The card priced the MLP's down-projection (512 -> 128) at C^2; the matrix actually holds 4C^2 numbers, and that slip across 4 blocks is the whole 196,608 gap. Nothing about Day 42's model changes - only its bookkeeping. LoRA forces this census anyway (you cannot wrap a matrix you have not enumerated), which is why tonight every count is counted, never formula'd.

The patches go on every weight matrix in the blocks: each head's key, query and value projections, the attention output projection, and both MLP matrices - 15 per block, 60 in total. Embeddings, LayerNorms and the LM head stay frozen: the norms have no matrix worth patching, and the embeddings must not move at all - which is why the journal corpus is written inside Day 42's 51-character alphabet (the code asserts it). An embedding for a character the base never trained would be random noise the adapters had to shout over. Rank r = 4, alpha = 8, so scaling alpha/r = 2 - Day 53's volume knob, set once and left alone.

What should the after-sample look like? Honest answer: recitation-flavored. The journal is 2,774 characters and the adapters hold 55,296 numbers - this patch can nearly memorize its corpus, the same regime as Day 42's Shakespeare. So the win is not literary quality; it is watching the voice move - same prompt, same seed, same temperature: Shakespeare before, journal after - while 814,643 base numbers provably never moved. That freeze / train / merge discipline, at 7B scale, is the fine-tuning economy of the whole modern stack (Day 63).

Analogy
Think of the base model as a read-only container base image: published once, checksummed, shared by every deployment. Full fine-tuning is rebuilding the image per customer. A LoRA adapter is a thin overlay layer on top - a small diff against the shared base, one per task, stacked at load time. Tonight you build one overlay (journal voice), verify the base layer's checksum never changed, and then squash: merging is flattening the overlay into a single deployable image once you no longer need to swap. One registry, one base, a shelf of tiny layers - the serving fleet from Days 68 and 71, wearing fine-tuning clothes.

Code it (~30 min)

def get_batch(src):
    """Random windows into src; y is x shifted by one (Day 42)."""
    ix = torch.randint(len(src) - block_size, (batch_size,))
    x = torch.stack([src[i:i + block_size] for i in ix])
    y = torch.stack([src[i + 1:i + block_size + 1] for i in ix])
    return x.to(device), y.to(device)


# ---------- the model: Day 42's classes, verbatim ----------
class Head(nn.Module):
    """One self-attention head with the causal mask (Day 38)."""

    def __init__(self, head_size):
        super().__init__()
        self.key = nn.Linear(n_embd, head_size)
        self.query = nn.Linear(n_embd, head_size)
        self.value = nn.Linear(n_embd, head_size)
        self.register_buffer(
            "tril", torch.tril(torch.ones(block_size, block_size)))

    def forward(self, x):
        _, T, _ = x.shape
        k = self.key(x)                                # (B, T, hs)
        q = self.query(x)                              # (B, T, hs)
        wei = q @ k.transpose(-2, -1) * k.shape[-1] ** -0.5
        wei = wei.masked_fill(self.tril[:T, :T] == 0,
                              float("-inf"))           # no peeking
        wei = F.softmax(wei, dim=-1)
        return wei @ self.value(x)


class MultiHeadAttention(nn.Module):
    """Heads in parallel, outputs concatenated + projected (Day 39)."""

    def __init__(self):
        super().__init__()
        hs = n_embd // n_head
        self.heads = nn.ModuleList([Head(hs) for _ in range(n_head)])
        self.proj = nn.Linear(n_embd, n_embd)

    def forward(self, x):
        return self.proj(torch.cat([h(x) for h in self.heads],
                                   dim=-1))


class FeedForward(nn.Module):
    """The block's MLP: widen, bend, narrow (Days 21/40)."""

    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(n_embd, 4 * n_embd),
            nn.ReLU(),
            nn.Linear(4 * n_embd, n_embd),
        )

    def forward(self, x):
        return self.net(x)


class Block(nn.Module):
    """Pre-norm block: norm -> attend -> add, norm -> mlp -> add
    (Day 40). Shape in = shape out: (B, T, C) throughout."""

    def __init__(self):
        super().__init__()
        self.ln1 = nn.LayerNorm(n_embd)
        self.attn = MultiHeadAttention()
        self.ln2 = nn.LayerNorm(n_embd)
        self.ffwd = FeedForward()

    def forward(self, x):
        x = x + self.attn(self.ln1(x))     # communicate
        x = x + self.ffwd(self.ln2(x))     # compute
        return x


class TinyGPT(nn.Module):
    """The whole stack: embed -> blocks -> norm -> head."""

    def __init__(self):
        super().__init__()
        self.token_embedding = nn.Embedding(vocab_size, n_embd)
        self.position_embedding = nn.Embedding(block_size, n_embd)
        self.blocks = nn.Sequential(
            *[Block() for _ in range(n_layer)])
        self.ln_f = nn.LayerNorm(n_embd)
        self.lm_head = nn.Linear(n_embd, vocab_size)

    def forward(self, idx, targets=None):
        B, T = idx.shape
        tok = self.token_embedding(idx)                    # (B,T,C)
        pos = self.position_embedding(
            torch.arange(T, device=idx.device))            # (T,C)
        x = self.blocks(tok + pos)                         # (B,T,C)
        logits = self.lm_head(self.ln_f(x))                # (B,T,V)
        loss = None
        if targets is not None:
            loss = F.cross_entropy(logits.view(B * T, vocab_size),
                                   targets.view(B * T))
        return logits, loss

    @torch.no_grad()
    def generate(self, idx, max_new_tokens, temperature=1.0,
                 greedy=False):
        """Predict, append, repeat - autoregression in one loop.
        Temperature divides the logits before softmax (Day 14):
        lower = safer picks, higher = wilder. Greedy = argmax."""
        self.eval()
        for _ in range(max_new_tokens):
            window = idx[:, -block_size:]        # crop to context
            logits, _ = self(window)
            logits = logits[:, -1, :] / temperature
            probs = F.softmax(logits, dim=-1)
            if greedy:
                nxt = probs.argmax(dim=-1, keepdim=True)
            else:
                nxt = torch.multinomial(probs, num_samples=1)
            idx = torch.cat([idx, nxt], dim=1)
        return idx

# ---------- Part 3: bolt on the adapters ----------
class LoRALinear(nn.Module):
    """Day 53's wrapper: a frozen nn.Linear plus a trainable
    low-rank patch. forward(x) = base(x) + (alpha/r) (x A^T) B^T.
    B starts at zero, so the patch contributes exactly nothing
    until training moves it. One change from Day 53, which ran
    CPU-only: A and B are born on the base weight's device."""

    def __init__(self, base, r, alpha=1.0):
        super().__init__()
        self.base = base
        for p in self.base.parameters():
            p.requires_grad_(False)            # freeze W and b
        d_out, d_in = base.weight.shape
        self.r = r
        self.scaling = alpha / r
        dev = base.weight.device
        self.A = nn.Parameter(torch.zeros(r, d_in, device=dev))
        self.B = nn.Parameter(torch.zeros(d_out, r, device=dev))

    def forward(self, x):
        patch = (x @ self.A.T) @ self.B.T      # squeeze, then lift
        return self.base(x) + self.scaling * patch

    def merged_weight(self):
        """W' = W + scaling * B x A - the patch, folded in."""
        with torch.no_grad():
            return self.base.weight + self.scaling * (self.B @ self.A)


def wrap(lin):
    """Swap one nn.Linear for its LoRA twin: A drawn small and
    random (so the patch CAN learn), B left at exactly zero
    (so at init it HASN'T)."""
    w = LoRALinear(lin, R, ALPHA)
    nn.init.normal_(w.A, std=0.02)
    return w

    block.ffwd.net[0] = wrap(block.ffwd.net[0])
    block.ffwd.net[2] = wrap(block.ffwd.net[2])

def get_module(root, path):
    obj = root
    for part in path.split("."):
        obj = obj[int(part)] if part.isdigit() else getattr(obj, part)
    return obj


lora_paths = [path for path, m in model.named_modules()
              if isinstance(m, LoRALinear)]
new_sd = {}
for k, v in model.state_dict().items():
    if any(k == p + suf for p in lora_paths
           for suf in (".A", ".B", ".base.weight", ".base.bias")):
        continue                     # adapter keys: replaced below
    new_sd[k] = v
for p in lora_paths:
    mod = get_module(model, p)
    new_sd[p + ".weight"] = mod.merged_weight()
    new_sd[p + ".bias"] = mod.base.bias
merged = TinyGPT().to(device)
merged.load_state_dict(new_sd)       # strict: keys+shapes must fit
with torch.no_grad():
    merged_logits, _ = merged(probe)
    adapted_logits, _ = model(probe)
mdiff = (merged_logits - adapted_logits).abs().max().item()
print(f"  merged model: fresh TinyGPT, W' = W + "
      f"{ALPHA / R:.1f} * B A folded into all {len(lora_paths)} "
